# 3D 공연장 — 교회 3층 다목적실 (중앙 원형 무대)

설계도(A-006)와 현장 사진으로 만든 웹 3D 공연장입니다. 설치 없이 브라우저(휴대폰 포함)에서 바로 열립니다.

## 사용법
- **걷기 / 1인칭**: 왼쪽 조이스틱(PC는 WASD·방향키)으로 이동, 화면 드래그로 시점 변경
- **시점 버튼**: 입구 · 공연자 사이 · 관객 첫 줄 · 전체 보기
- **조명**: 공연 조명 / 리허설 조명, "조명 조절"에서 스탠드·벽·천장등 밝기와 색(오렌지~흰색)

## 구성
| 항목 | 내용 |
|---|---|
| 공간 | 30m × 18m, 기둥 간격 7.5m, 맞배지붕 (도면 기준) |
| 편성 | 보컬 7 · 일렉 1 · 베이스 1 · 드럼 1 · 건반 2, 중앙 원형으로 서로 마주 봄 |
| 조명 | 좌·우 측벽 앞 스탠드 조명 2대(4구 LED × 2단), 기둥 벽 조명 |
| 관객 | 공연자를 둘러싼 원형, 십자 통로 4개 |

높이(측벽 5m, 용마루 8m 등)는 사진으로 추정한 값입니다. 실측값은 `index.html` 맨 위 `VENUE`, 공연 구성은 `SHOW` 값만 바꾸면 됩니다.
도면에서 뽑은 좌표 데이터는 `data/venue_3F_plan.json`에 있습니다.

## 파일
- `index.html` — 3D 페이지 전체 (Three.js r160, CDN에서 불러옴)
- `tex/` — 바닥·벽·기둥·카펫 사진 질감
- `data/venue_3F_plan.json` — 도면 좌표 데이터 (단위 mm)
